# SOLD OUT · 생존약국

작은 1인 약국의 하루를 운영하는 한국어 3D 경영 게임입니다. **배경음·업무 효과음과 음량 설정을 갖춘 0.7 빌드**이며, 마스터 지침 전체의 출시 완료 버전은 아닙니다.

## 바로 실행

Windows에서 **`게임 실행.cmd`를 더블클릭**합니다. 브라우저가 열리면 `약국 문 열기`를 누르세요. 실행 창은 플레이하는 동안 열어둡니다.

이미 실행 중이면 <http://127.0.0.1:5173> 에서 이용할 수 있습니다.

다른 개발 환경에서는 Node.js 22.6 이상과 npm 또는 pnpm을 사용합니다.

```sh
npm install
npm run dev
```

## 플레이

- 첫날 자금 500만 원, 약사 1명으로 시작합니다. 하루는 정상 속도로 약 10분입니다.
- 고객이 실제로 매대를 찾아 상품을 집고 줄을 섭니다. 약사는 접수·약 찾기·조제·포장·전달을 수행합니다.
- 기본적으로 업무가 자동 배정됩니다. 오른쪽 업무 카드를 선택하면 해당 업무를 우선 처리합니다. 직원 화면에서는 업무 종류별 우선순위를 바꿀 수 있습니다.
- **매대를 클릭**하면 해당 상품의 재고와 재진열 버튼을 볼 수 있습니다.
- **발주**에서 공급업체와 수량을 선택합니다. 실제 상자가 도착하고, 직원이 정리하면 창고 재고가 늘어납니다. **재고**에서 재진열합니다.
- **직원**에서 계산·진열·조제를 분담합니다. **매장**에서 설명 업무를 줄이는 POP와 가구를 설치합니다.
- **매장**에서 8평→12평→16평으로 확장합니다. 창고·직원 한도와 임대료가 함께 바뀝니다. 창고 선반은 보관량을 120개 늘리고, 벤치는 손님의 인내심을 늘립니다.
- **배치 편집**에서 상품 매대와 구입한 가구를 이동·회전합니다. 편집 중에는 시간이 멈추며, 초록 미리보기 위치에 클릭해서 확정합니다. 출입구·대기줄·사람을 가두는 배치는 거부됩니다.
- **오늘 영업 마감**을 누르면 새 고객 입장을 멈추고 남은 고객을 처리한 뒤 정산합니다.
- **뉴스**에서 10단계 위기 현황과 내일 수요·공급을 확인합니다. DAY 4부터 상승하고 DAY 8 정점, DAY 12 일상 회복으로 진행합니다. 발주 한도는 상품·공급업체별 하루 물량이며 다음 날 갱신됩니다. 이미 주문한 가격과 배송 시간은 유지됩니다.
- 매장별 실내 한도는 8/12/18명이며, 초과 손님은 밖에서 최대 32명이 기다립니다. 총 50명까지 관리하고, 빈자리가 나면 선착순으로 입장합니다. 밖에서도 인내심이 줄어들며 마감 후에는 이미 기다리던 손님까지 처리합니다.
- 상품 매대는 한 명씩 이용하고 같은 매대를 찾는 손님은 빈 위치에서 기다립니다. 대기 중에도 인내심이 줄어들므로 혼잡할 때는 계산과 재진열을 분담하세요.
- 이동 중 다른 사람이 앞을 막으면 빈 통로로 우회하거나 잠시 기다립니다. 직원은 업무를 마친 뒤 빈 대기 위치로 물러납니다. 중심 간 0.42m 거리를 기준으로 처리하며 팔·의복의 세밀한 접촉은 별도로 계산하지 않습니다.
- 브라우저에 30초마다 자동 저장됩니다. 설정에서 수동 저장과 불러오기를 할 수 있습니다. 다른 브라우저나 포트의 저장은 공유되지 않습니다.
- 첫 클릭 또는 키보드 조작 이후 배경음과 효과음이 시작됩니다. **설정 → 소리 테스트**에서 네 음과 출력 막대를 확인하세요. 전체·효과음·배경음 음량을 각각 조절하고 전체 음소거할 수 있으며 설정은 자동 저장됩니다. 막대가 움직이는데 들리지 않으면 브라우저 탭 음소거와 출력 장치를 확인하세요. 다른 탭으로 이동하면 소리를 멈춥니다.

| 조작 | 기능 |
|---|---|
| 휠 | 확대/축소 |
| 우클릭 드래그 | 화면 이동 |
| Q / E | 90도 회전 |
| R | 배치 중인 가구 90도 회전 |
| Space | 일시정지/재개 |
| Esc | 패널 닫기/배치 취소 |

## 개발과 검증

```sh
npm test
npm run build
npm run preview
npm run test:browser
npm run test:building
npm run test:crisis
npm run test:crowd
npm run test:browsing
npm run test:movement
npm run test:audio
```

브라우저 검증은 Microsoft Edge와 로컬 `4173` 프리뷰 서버를 사용합니다. `GAME_URL`로 주소를 바꿀 수 있습니다. 스크린샷과 상태 기록은 `artifacts/`에 생성됩니다.

실행은 로컬 전용이며 배포나 외부 계정이 필요하지 않습니다. 글꼴은 Google Fonts를 요청하고 네트워크가 없으면 시스템 한글 글꼴을 사용합니다. 3D 모델과 효과음은 코드로 제작한 자체 에셋입니다.

## 범위와 후속 작업

현재: 15종 상품, 3개 공급업체, 10개 처방 정의, 8개 고객 프로필, 3개 직원 역할, 8개 POP, 15개 뉴스, 재고·경제·업무·배송·저장·정산·기초 수요 변화.

현재 추가: 3단계 확장, 상품 매대 이동/회전, 화분·벤치·창고 선반 구매/편집/판매, 보관 한도, 이전 저장 자동 이전.

후속: 카운터·조제실·출입문과 벽 구조 편집, 더 다양한 배치에서의 군중 스트레스 검증과 성능 최적화, 장기 위기 캠페인 난이도 조정, 완전한 사운드/캐릭터 애니메이션 세트. 50명 렌더링은 로컬 Edge에서 확인했으며 모든 기기의 성능을 보장하지 않습니다. 자세한 기준은 `MASTER_DIRECTIVE.md`, 구현 구조와 검증 기록은 각 개발 문서를 참고하세요.
